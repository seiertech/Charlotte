# Charlotte Book Factory Steering

Charlotte is a Kiro-ready Book Factory for producing a complete first draft from supplied foundation material.

Core workflow:
Outliner → Researcher → Drafter → Persona Reviewers → Continuity Warden → Safety Warden → Voice Warden → Editor → Assembler.

Rules:
- Do not collapse all roles into one prompt.
- Each agent must produce a handoff artefact.
- Do not overwrite foundation/Me_OS_Foundation.md.
- Keep generated manuscript content inside output/.
- Preserve config.yaml as the workflow control file.
- First priority is producing output/full_first_draft.md.
- Keep the first version simple and runnable.
- Do not over-engineer this into a SaaS platform.
